In Tree-Based Models (like Random Forest): Feature importance is calculated based on the reduction in impurity (e.g., Gini impurity or entropy) when the feature is used to split data in decision trees. Features that result in larger reductions in impurity are considered more important. In General: High importance: Features that significantly influence the target variable. Low importance: Features that have little to no influence on predictions.

# Function to visualize feature importance
def plot_feature_importance(model, feature_names):
    """
    Plots the importance of features based on the trained Random Forest model.
    """
    importances = model.feature_importances_  # Extract feature importance
    indices = importances.argsort()[::-1]    # Sort features by importance
    plt.figure(figsize=(8, 6))               # Set plot size
    plt.bar(range(len(feature_names)), importances[indices], color='skyblue', align='center')  # Bar plot
    plt.xticks(range(len(feature_names)), [feature_names[i] for i in indices], rotation=45)    # Label x-axis
    plt.title("Feature Importance")          # Add title
    plt.show()                               # Show the plot

    verbose=2,                                # Show detailed progress
    n_jobs=-1                                 # Use all available CPU cores

Interpretation of Results¶

Random Forest Results¶

The Random Forest classifier performed significantly better than the Decision Tree in terms of accuracy and balanced class predictions. However, the model struggled with minority classes like 3, 4, and 8, where precision, recall, and F1-scores were all 0.00. This suggests that the Random Forest failed to effectively learn patterns for these underrepresented classes, despite using class weights to address imbalance. While the macro-average metrics (precision: 0.34, recall: 0.35) were low due to these minority class challenges, the weighted averages (precision: 0.67, recall: 0.70) were higher, reflecting better performance on majority classes.

Decision Tree Results¶

The Decision Tree classifier achieved a lower overall accuracy of 53%, indicating it struggled to generalize as effectively as the Random Forest. The simpler nature of the Decision Tree led to reduced predictive power, especially for minority classes, where the performance was poor. Similar to the Random Forest, it failed to predict the minority classes (3, 4, and 8), with precision, recall, and F1-scores of 0.00.

For majority classes, the Decision Tree showed moderate performance. For example, class 5 had a recall of 0.91, meaning most instances of this class were identified correctly, but a lower precision of 0.54, indicating a higher number of false positives. The weighted average metrics (precision: 0.49, recall: 0.53) were also much lower compared to the Random Forest, reflecting overall weaker performance.

Key Insights¶

  1. The Random Forest outperformed the Decision Tree in terms of accuracy and balanced predictions across majority classes due to its ensemble nature, which reduces overfitting and captures more complex patterns.
  2. Both models struggled with minority classes (3, 4, and 8) because of the class imbalance in the dataset. The metrics for these classes were consistently 0.00, indicating the models failed to learn patterns for these underrepresented groups.
  3. While the Random Forest demonstrated stronger performance overall, further improvements are necessary to handle class imbalance effectively. Techniques like advanced class-weight adjustments could improve predictions for minority classes.
  4. Random Forest is better suited for this task, but addressing class imbalance remains crucial for achieving a well-balanced and robust model.

This analysis highlights the strengths and weaknesses of both models, providing a foundation for further optimization and improvement.
